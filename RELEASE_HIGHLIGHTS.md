- **Cleaner Live routing:** selected-strip controls now use one compact Channel selector, keep device selection in Settings, and move channel deletion out of the main pane.
- **Better timeline behavior:** monitoring keeps the timeline line stationary, while recording follows the active playhead and grows horizontally with the take.
- **Smoother update flow:** the update dialog no longer offers the update action again while a download is already in progress.
- **More reliable console startup:** channel-state watching now starts reliably when the console opens.
