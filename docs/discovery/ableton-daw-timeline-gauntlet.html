Borrow From Ableton

  • Arrangement is a left-to-right time surface: ruler above, stacked tracks below, clips positioned by time.
  • The global playhead, insert marker, time selection, and selected clip are separate states with different click targets.
  • Horizontal zoom changes how much time the same pixels represent; waveform rendering, clip width, gridlines, scrub hit testing, beat/time ruler labels, and playhead x all share that scale.
  • Loop is a visible global brace with start and length, not only a hidden toolbar toggle.

Current Gaps

  • DAW_TIMELINE_PX_PER_SECOND = 8 is fixed, so the UI cannot compress or expand time.
  • There is no BPM-backed bars/beats ruler yet; elapsed seconds are available, but musical time is not displayed like Ableton.
  • Waveform clip widths and live waveform columns use the fixed scale, so zoom would currently drift or require duplicate math.
  • Playback has Play/Stop/Loop/Return, but no DAW-grade insert marker, loop brace, or visible scrub zone.
  • Follow-scroll exists as completed work, but needs a regression gauntlet across recording, loaded playback, manual scroll, and zoom.

Gauntlet

  • At every zoom level, the same time maps to the same x for ruler tick, gridline, waveform clip edge, scrub target, and playhead.
  • Loaded takes and live recording both keep waveform content aligned with elapsed time after resize and scroll.
  • Click background sets a play position; click clip selects it; drag ruler/scrub area seeks without accidentally changing track selection.
  • Loop on/off, loop start, and loop length are visible and testable; Return resets position without losing the loop range.
